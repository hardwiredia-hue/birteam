SISTEMA DE DISEÑO

Organizá partidos, sumate a los de otros. El sistema nace del isotipo — la "b" verde lima sobre negro — así que el verde queda como único acento y se reserva para la marca, la acción principal de cada pantalla y el estado "Voy". Base tipográfica: Archivo Black Italic para títulos y cifras, Instrument Sans para lectura, Spline Sans Mono para horarios y datos tabulares. Un solo radio por escala (6px controles, 12px tarjetas) — nada de píldoras.
